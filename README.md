# 체험시청(가상) 체험용 데모 사이트

이 웹사이트는 실제 기관이 아닙니다. 공공 웹사이트에 숨겨 심은 불법광고를 찾는 점검 도구를 연습하고 시연하려고 만든 가짜 사이트입니다. 쪽마다 맨 위에 그 사실을 적은 띠가 있습니다.

- 주소: https://isaaceryn.github.io/hidden-ad-demo-site/
- 광고 문구와 연락처(`DEMO01`, `@demo_fake_bet` 같은 것)는 모두 지어낸 것입니다. 실제 업체나 계정이 아닙니다.
- 신고 안내 글의 상담 번호(한국도박문제예방치유원 1336, 금융감독원 1332)만 실제 번호입니다.
- 화면에 보이지 않게 숨긴 광고와, 광고가 아닌 정상적인 숨김(화면 낭독기용 글, 접힌 질문의 답 등)이 함께 들어 있습니다.
- 쪽마다 검색 엔진 제외 표시(noindex)를 넣었습니다.
- 스크립트·입력 양식·외부 주소가 없는 정적 파일뿐입니다.

## About

A fake website of a fictional city hall, made for practicing with a tool that detects hidden illegal ads on public websites. Every page carries a banner saying it is a fake demo. All ad texts and contacts are fictitious; only the two helpline numbers in the reporting guide are real.
